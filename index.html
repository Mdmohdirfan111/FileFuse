DataPro Tools

Advanced Excel & PDF Processing Utilities

1. File Concatenator

ℹ️

Use: Merge multiple PDF, XLSX & CSV files into one Excel file.

Important:

  • All files must have the same column headers
  • Output will be downloaded as Excel (.xlsx)

2. Monthly PJP Generator

ℹ️

Use: Generate monthly PJP sheet from your route plan data.

Input Format Example:

Plan Store 1 Store 2 Store 3 Store 4
Route-1 HEALTH & GLOW - TOWLICHOWKI, HYD HEALTH & GLOW - ALKAPURI, HYD CENTRO - KUKATPALLY, HYD HEALTH & GLOW - SUJANA FORUM MALL, HYD

Important:

  • Column names & spelling must match exactly

3. Floater Incentive Tracker

ℹ️

Use: Generate incentive tracker for floater counters.

Input Format Example:

Counter_Code Store_Name
CTR001 HEALTH & GLOW - TOWLICHOWKI
CTR002 HEALTH & GLOW - ALKAPURI

Important:

  • Column names & spelling must match exactly

4. Catalogue XLookup

ℹ️

Use: Match SOH data with catalogue using Description column.

Important:

  • Upload both catalogue and SOH files
  • Matching is done based on "Description" column
  • Unmatched records will also be included in output
